# RPI Phase Details: Optional post-shaping validation

## P01 Validation authority

Classify source-span identity, source-version identity, cited-span existence, and
approval-bound exclusion enforcement as non-bypassable. All other deterministic
preservation findings remain available for review and optional repair.

## P02 Artifact review governance

Persist the retained candidate's findings on the artifact. Publication approval
must echo the complete finding identity set so stale or partial review cannot pass.

## P03 Validation and release

Run targeted and full repository gates, update affected operational documentation,
then release an immutable production revision and verify health and traffic.
